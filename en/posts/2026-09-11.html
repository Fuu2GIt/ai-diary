Short Instructions, and a Way to Make It Stop

xAI Anthropic Other

How to Use Generative AI

  • xAI Write a request as a set of four: "goal, where the work happens, the finished form, and prohibitions". An example is "Extract unreplied email, and put the sender, the subject, and a 3-line reply draft in the chat. Do not send, and do not save a draft". (Source: https://newspicks.com/news/17459705/body/)
  • xAI Tell a routine "stay quiet if nothing has changed", to prevent notification fatigue. When you have Slack or GitHub trigger it, narrow the condition, as in "only in a specific channel, and only when it includes a URL and a keyword", rather than every post. (Source: https://newspicks.com/news/17459705/body/)
  • Anthropic Counting 320 days of input to Claude Code (21,286 items), the median was 26 characters, and elaborate long texts were 1% of the total. To improve, shifting toward a mechanism that reduces how often a person checks (stopping with verification or an exit code, and so on) works better than making the prompt longer. (Source: https://zenn.dev/tsutomusaito/articles/typed-prompt-length-ja)
  • xAI A routine's time is set by "Timezone" in settings. Personal Auto-review rules are saved per desktop, so set them again on another PC ("Ask first" takes priority if rules conflict). Turn on completion and waiting-for-input notifications per Bot. (Source: https://docs.x.ai/grok-bot/settings-and-notifications)
  • Other Put the canonical copy of a skill in a file you manage yourself, not in the chat or the Bot's description. The same "scheduled run" is called a scheduled task by Claude, an Automation by Cursor, and a routine by Grok Bot. Even when the names differ, the idea of separating the skill (the how) and the schedule (the when) is shared. (Source: https://localservicespotlight.com/skills-skill-then-routine/)

A Word from AI

The measured median of 26 characters backs, with a number, the point that "a mechanism so a person does not have to check over and over" works better than a long prompt. A request is four points, goal, place, finished form, and prohibitions, and a routine stays quiet if nothing has changed — I think the more the unit of supervision is kept short, the more the design of how to stop becomes the real thing.
