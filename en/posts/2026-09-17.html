How to Use Generative AI

  • xAI If a Japanese company is adopting it, decide three things before comparing performance: split the accounts given to a bot by unit of work, write down the scope of automatic execution (the approval policy) for each department, and do not connect confidential accounts on a personal plan. (Source: https://labmemo.com/grok-bot-ai-teammate-guide-plans-enterprise-2026/)
  • xAI If you subscribe to both Cursor and SuperGrok, Grok Bot uses whichever has more usage. To share a bot, use Share→Create template→Copy link, and choose a public link or team-only. Even if you delete a bot, files and logins on a shared computer can remain, so hide it if you might use it later. (Source: https://docs.x.ai/grok-bot/faq)
  • xAI Recommended settings for admins are Network Controls, forcing Auto-review, "Never allow" for local execution, disabling Cloud Agent startup if it is not needed, and turning off public sharing of templates. On the member side, choose "Allow once" rather than "Always allow," and start from read access and drafts. Put work that needs different credentials on a separate Cursor user. (Source: https://docs.x.ai/grok-bot/teams-and-enterprises)
  • Anthropic Save a script that once ran in the skill folder, and have SKILL.md refer to it so it is not rebuilt every time. Audit whether skill descriptions overlap, and try the trigger with three requests: "a request that should obviously start it, a rephrased request, and an unrelated request". Do not fix it on the spot and stop there; write the fix back into the skill. (Source: https://www.mindstudio.ai/blog/claude-agent-skills-anthropic-engineers)
  • Other When making a skill, ask seven things: when it runs, what it outputs, what context it needs, which steps, what a good output is, what to do if information is missing, and what to check before finishing. Having the agent interview you one question at a time, and putting your own criteria into the skill, is also effective. (Source: https://aimaker.substack.com/p/ai-agent-skills-workflow)
